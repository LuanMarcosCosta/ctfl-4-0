# Ferramentas de automação

## O que é?

Ferramentas usadas para automatizar testes, execução de pipelines e geração de evidências.

## Para que serve?

Reduz trabalho repetitivo e torna feedbacks de qualidade mais rápidos.

## Como usar?

Selecione ferramentas pelo tipo de sistema, linguagem, integração e capacidade de manutenção do time.

## Exemplo

Usar Playwright para testes web e um pipeline de CI para executá-los em cada pull request.

## Pontos de atenção

- A escolha deve considerar custo de manutenção, não apenas facilidade inicial.
