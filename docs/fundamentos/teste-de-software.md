# Teste de software

## O que é?

Atividade de avaliar um produto para encontrar problemas e gerar informações sobre sua qualidade.

## Para que serve?

Reduz riscos e apoia decisões sobre a liberação do software.

## Quando usar?

Desde a revisão de requisitos até a validação após mudanças.

## Como usar?

Defina um objetivo, prepare condições de teste, execute, compare o resultado e comunique evidências.

## Exemplo

Validar se um usuário consegue concluir uma compra com cartão aprovado.

## Pontos de atenção

- Testar não prova a ausência de defeitos.
- Priorize riscos relevantes ao produto.
