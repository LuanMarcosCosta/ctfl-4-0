# Princípios de teste

## O que é?

Princípios são orientações gerais para planejar e executar testes de forma eficaz.

## Para que serve?

Evita expectativas irreais e direciona esforço para os maiores riscos.

## Como usar?

Use os princípios para combinar técnicas, começar cedo e revisar a estratégia conforme o contexto.

## Exemplo

Em vez de testar todas as combinações possíveis, selecione casos representativos e de maior risco.

## Pontos de atenção

- A abordagem deve ser adaptada ao contexto.
- Ausência de defeitos encontrados não significa produto adequado ao uso.
