# Conceitos de API

## O que é?

Conjunto de noções para entender endpoints, requisições, respostas, contratos e autenticação.

## Para que serve?

Cria uma linguagem comum para testar a comunicação entre sistemas.

## Como usar?

Documente entradas, saídas, códigos de resposta, regras e dependências de cada operação.

## Exemplo

Um `POST /pedidos` recebe itens e retorna o identificador do pedido criado.

## Pontos de atenção

- Contrato não é apenas o formato do JSON: inclui comportamento e erros esperados.
