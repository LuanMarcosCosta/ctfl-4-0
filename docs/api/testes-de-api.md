# Testes de API

## O que é?

Verificações de comportamento, contrato e integração de uma API.

## Para que serve?

Identifica problemas em regras de serviço antes ou independentemente da interface visual.

## Como usar?

Teste respostas válidas e inválidas, autorização, validações, contratos e efeitos persistidos.

## Exemplo

Enviar um pedido sem item e verificar a resposta de validação esperada.

## Pontos de atenção

- Não dependa de dados compartilhados ou estado deixado por outros testes.
