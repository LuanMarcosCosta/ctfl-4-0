# Boas práticas de API

## O que é?

Práticas para tornar testes de API claros, confiáveis e úteis para o time.

## Como usar?

Versione contratos, controle dados, cubra erros relevantes e mantenha asserções específicas.

## Exemplo

Após criar um recurso de teste, removê-lo ao fim do cenário para evitar interferência futura.

## Pontos de atenção

- Evite validar apenas código HTTP sem verificar o corpo e os efeitos da operação.
