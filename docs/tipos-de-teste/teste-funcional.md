# Teste funcional

## O que é?

Teste que avalia se funções e regras de negócio entregam o comportamento esperado.

## Para que serve?

Verifica requisitos funcionais sob a perspectiva de quem usa ou integra com o sistema.

## Como usar?

Derive casos a partir de requisitos, critérios de aceite e regras de negócio.

## Exemplo

Verificar se um cupom válido aplica o desconto correto ao carrinho.

## Pontos de atenção

- Também valide cenários negativos e permissões.
