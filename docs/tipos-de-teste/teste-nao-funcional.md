# Teste não funcional

## O que é?

Teste de características de qualidade, como desempenho, segurança, usabilidade e confiabilidade.

## Para que serve?

Avalia se o sistema é adequado para uso além de apenas funcionar corretamente.

## Como usar?

Transforme atributos de qualidade em critérios mensuráveis e execute testes no ambiente adequado.

## Exemplo

Validar se uma busca responde em até dois segundos sob a carga esperada.

## Pontos de atenção

- Critérios vagos, como “ser rápido”, não são testáveis.
