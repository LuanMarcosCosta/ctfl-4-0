# Quando automatizar

## O que é?

Decisão de aplicar automação a um teste ou atividade de verificação.

## Para que serve?

Direciona investimento para cenários que ganham repetibilidade, velocidade ou confiabilidade.

## Como usar?

Considere frequência, estabilidade, custo de manutenção, risco e valor do feedback.

## Exemplo

Automatizar o fluxo crítico de login executado a cada pull request.

## Pontos de atenção

- Não automatize um processo instável sem considerar sua manutenção.
