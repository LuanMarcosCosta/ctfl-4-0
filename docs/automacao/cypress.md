# Cypress

## O que é?

Ferramenta para automação de testes de aplicações web, com foco em execução no navegador.

## Para que serve?

Automatiza verificações de interface e fluxos web durante o desenvolvimento e integração contínua.

## Como usar?

Crie testes determinísticos, use comandos legíveis e execute a suíte no CI.

## Exemplo

Validar que um usuário autenticado consegue adicionar um produto ao carrinho.

## Pontos de atenção

- Avalie compatibilidade, paralelismo e requisitos do projeto antes da adoção.
