# Boas práticas de automação

## O que é?

Práticas para tornar testes automatizados confiáveis, legíveis e sustentáveis.

## Como usar?

Mantenha testes independentes, dados controlados, seletores estáveis e relatórios úteis.

## Exemplo

Usar atributos de teste em vez de seletores visuais frágeis para localizar elementos da tela.

## Pontos de atenção

- Trate testes instáveis como defeitos da suíte, não como ruído aceitável.
