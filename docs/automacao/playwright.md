# Playwright

## O que é?

Ferramenta para automação de navegadores e testes end-to-end de aplicações web.

## Para que serve?

Permite validar jornadas de usuário em múltiplos navegadores e integrar resultados ao CI.

## Como usar?

Escreva testes independentes, controle dados e use locators acessíveis e estáveis.

## Exemplo

Executar a jornada de checkout nos navegadores suportados antes de publicar uma versão.

## Pontos de atenção

- Testes de interface exigem atenção a ambiente, dados e sincronização.
