# Métricas de teste

## O que é?

Medidas usadas para acompanhar o trabalho de teste e apoiar decisões.

## Para que serve?

Ajuda a entender progresso, riscos, eficácia e tendências.

## Como usar?

Escolha métricas que respondam a uma decisão real e interprete-as com contexto.

## Exemplo

Acompanhar defeitos críticos abertos por versão para apoiar uma decisão de release.

## Pontos de atenção

- Não use métricas isoladas para avaliar pessoas ou qualidade total.
