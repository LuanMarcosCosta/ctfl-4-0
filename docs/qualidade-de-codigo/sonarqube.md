# SonarQube

## O que é?

Plataforma de análise contínua de qualidade e segurança de código.

## Para que serve?

Centraliza resultados de análise estática, cobertura e quality gates.

## Como usar?

Integre o scanner ao pipeline e ajuste o perfil de regras às linguagens e políticas do projeto.

## Exemplo

Uma pull request recebe análise de código novo e só pode ser integrada após atender ao gate definido.

## Pontos de atenção

- Cobertura é um indicador, não uma garantia de qualidade.
