# Code review

## O que é?

Revisão colaborativa de mudanças de código antes de sua integração.

## Para que serve?

Encontra problemas cedo, dissemina conhecimento e melhora a manutenibilidade.

## Como usar?

Revise mudanças pequenas, use critérios claros e trate comentários como colaboração técnica.

## Exemplo

Antes do merge, verificar se a alteração inclui testes, tratamento de erro e nomes compreensíveis.

## Pontos de atenção

- Revisão não substitui execução de testes automatizados.
