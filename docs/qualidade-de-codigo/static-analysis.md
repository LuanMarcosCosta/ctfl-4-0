# Análise estática

## O que é?

Avaliação automatizada do código sem executar o sistema.

## Para que serve?

Detecta padrões de erro, vulnerabilidades, duplicação e problemas de estilo.

## Como usar?

Execute analisadores no editor e no pipeline, com regras adequadas ao projeto.

## Exemplo

O pipeline sinaliza uma variável não utilizada e uma possível injeção de comando.

## Pontos de atenção

- Regras devem ter propósito; alertas ignorados em massa reduzem valor.
