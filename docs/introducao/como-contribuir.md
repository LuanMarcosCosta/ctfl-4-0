# Como contribuir

## Objetivo

Orientar como novos artigos devem ser escritos e publicados nesta wiki.

## Regras

1. Todo artigo deve ser escrito em [markdown](https://www.markdownguide.org/cheat-sheet/).
1. Apenas artigos relevantes para o dia a dia do time de QA devem ser disponibilizados nesta wiki.
1. Todo artigo deve conter uma seção ***Objetivo***.
1. Os artigos devem seguir a estrutura de categorias existente. Caso necessário, uma nova categoria poderá ser criada.
1. Todo artigo deve ter uma seção de *keywords* para facilitar a busca por conteúdo.
1. O nome dos arquivos deve ser escrito em minúsculo e separado por `hífen`.
1. Atenção à LGPD: os artigos não devem conter dados pessoais de clientes ou usuários.

## Fluxo de publicação

1. Crie uma nova branch com o prefixo da categoria do artigo seguido de uma breve descrição. Exemplo: `introducao/como-configurar-ambiente-de-testes`.
1. Ao concluir a escrita do artigo, abra um pull request para a branch principal.
1. O pull request deve ter ao menos duas aprovações.
1. Durante o review, verifique se os padrões de escrita estão sendo observados.
1. As imagens utilizadas devem ser otimizadas para não comprometer o carregamento das páginas.
