# Glossário

## Como usar?

Consulte esta página para uma definição rápida dos termos usados na Knowledge Base. As definições serão ampliadas gradualmente.

| Termo | Definição inicial |
| --- | --- |
| QA | Sigla para Quality Assurance. |
| Quality Assurance | Práticas para promover qualidade no processo e no produto. |
| Quality Engineering | Disciplina que integra qualidade à engenharia de software. |
| Teste | Atividade de avaliar um produto e gerar informações sobre sua qualidade. |
| Erro | Ação humana que pode introduzir um defeito. |
| Defeito | Imperfeição em um artefato que pode causar uma falha. |
| Falha | Comportamento incorreto observado durante a execução. |
| Caso de teste | Conjunto de condições, ações e resultados esperados para uma verificação. |
| Cenário de teste | Situação de uso ou comportamento a ser avaliado. |
| Teste de regressão | Teste para identificar efeitos indesejados de mudanças. |
| Automação | Uso de ferramentas e código para executar verificações repetíveis. |
| Smoke Test | Verificação rápida de funcionalidades essenciais. |
| Sanity Test | Verificação focada em confirmar que uma mudança específica está utilizável. |
| Teste exploratório | Abordagem que combina aprendizado, desenho e execução de testes. |
| Particionamento de equivalência | Técnica que seleciona representantes de classes de entrada equivalentes. |
| Valor limite | Valor na fronteira de uma faixa ou regra de negócio. |
